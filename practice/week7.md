# 7주차 실습 기록

## 사용한 에셋
- **이미지**: 없음 (Pygame 기본 도형 `pygame.draw` 활용)
- **사운드**: 없음 (시각적 피드백 위주 구현)
- **데이터 구조**: `leaderboard.json` (로컬 데이터 저장용)

## 사용한 AI 프롬프트
- How to play 창이 나왔을 때 바로 플레이 화면으로 넘기지 말고, 3초 뒤에 넘길 수 있도록 하고 시각적인 타이머를 추가해달라고 하였다.
- 게임오버 화면에서 메뉴로 돌아가는 키를 스페이스바 하나로 통합하고 UI를 중앙 정렬해달라고 하였다.
- 닉네임 입력 시스템과 리더보드 기능을 추가하고 전체적인 화면 크기를 1600x900으로 키워달라고 하였다.
- 오늘 업데이트한 내용을 핵심적인 5가지 사항으로 정리해달라고 하였다.

## AI 답변에서 도움이 된 것
- **시스템 통합 능력**: 메인 메뉴, 닉네임 입력, 게임 루프, 리더보드라는 복잡한 흐름을 하나의 스크립트로 오류 없이 통합해준 점이 매우 유용했다.
- **UX 디테일 구현**: 단순히 기다리는 것이 아니라 '줄어드는 색막대' 같은 시각적 요소를 제안하고 코드로 바로 구현해 주어 게임의 완성도가 높아졌다.
- **자동 정렬 로직**: 화면 크기가 커짐에 따라 발생한 텍스트 치우침 문제를 `get_width()`를 활용한 중앙 정렬 공식으로 깔끔하게 해결해 주었다.

## AI 답변을 수정하거나 버린 것
- **불필요한 키 입력 제거**: 처음에는 메뉴 이동 키가 'Q'로 설정되었으나, 조작 일관성을 위해 스페이스바 하나로 통일하도록 수정 요청하였다.
- **설명 텍스트 간소화**: 튜토리얼 창의 설명이 너무 길어 가독성이 떨어졌기에, 핵심 단어 위주의 '초간단' 버전으로 수정을 요구하였다.
- **코드 제공 방식 교정**: 부분 코드만 줄 경우 전체 흐름을 파악하기 어려워, 수정 시마다 '전체 코드'를 제공하도록 가이드라인을 설정하였다.

## 적용 결과
- **잘 된 것**: 닉네임 저장부터 랭킹 확인, 튜토리얼 확인 후 게임 진입으로 이어지는 '게임다운 구색'이 완벽하게 갖춰졌다. 1600x900의 넓은 해상도 적용도 성공적이다.
- **어려웠던 것**: 기능이 많아지면서 기존의 패링 로직이나 장애물 이동 로직이 꼬이는 경우가 있었으나, 지속적인 피드백을 통해 복구하였다.
