# 12주차 실습 기록


## 1. 제일 흥미로웠던 던전 생성기 (BSP)
세 가지 코드 중에서 `bsp_dungeon.py`가 제일 흥미로웠다. 화면을 반으로 툭툭 쪼개 가면서 방을 만드는 원리(이진 공간 분할)도 신기했지만, 대박인 건 통로 연결 부분이었다. 방끼리 복잡하게 얽힌 길 중에서 수학 공식(MST)을 써서 쓸데없는 중복 길만 빨간색으로 골라내 싹 지워버리고, 딱 필요한 길만 남겨서 깔끔한 던전을 완성하는 연출이 아주 직관적이고 보는 맛이 있었다. 


## 2. 기말 프로젝트에 어떻게 써먹을까?
안 그래도 기말 과제 빌드업 중인데 아이디어가 몇 개 스쳐 지나갔다.
 - 로그라이크/RPG로 갈 경우: 스테이지 넘어갈 때마다 맨날 똑같은 맵 나오면 지루하니까, 이 BSP 코드를 응용해서 매번 새로운 무작위 던전을 만들면 게임 퀄리티가 확 올라갈 것 같다. 알고리즘이 방을 만들고 나면, 그 방 한가운데에 보스 몬스터나 보물상자가 자동으로 뚝 떨어지게 스폰 위치를 짜주면 딱일 듯하다.
 - 쿠키런 같은 러닝 게임으로 갈 경우: 테라리아나 쿠키런처럼 끝없이 오른쪽으로 달리는 게임을 만들 때 완전 찰떡일 것 같다. 맵을 미리 일일이 그려두지 않아도 펄린 노이즈가 알아서 실시간으로 무한한 땅을 만들어주니까 편리하다. 노이즈가 계산해 준 땅의 높낮이(y값)에 맞춰서 가시 장애물이나 코인이 땅바닥에 착 달라붙어서 나오게 배치하면 게임 하나 뚝딱 완성될 것 같다.
